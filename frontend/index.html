Adaptive Information Selection in Microplastic Polymer Classification

Instead of evaluating every computer vision block, this system actively maintains a Bayesian posterior over polymer classes and dynamically selects the measurement that maximizes Expected Information Gain per unit cost (EIG / Cost), stopping as soon as confidence is reached.
